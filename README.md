# Cihuy - #1 LegendsPVP Server

Static website for the **Cihuy** Minecraft LegendsPVP server.

## Tech

- Pure HTML + CSS + JS
- Multi-language toggle (ID / EN)
- Server status via `https://api.mcsrvstat.us/3/cihuy.xyz`
- Staff skins via `https://mineskin.eu/armor/bust/<nickname>/100.png`

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. On Vercel:
   - Import the GitHub repo.
   - Framework: **Other**
   - Build command: _empty_ (no build step)
   - Output directory: `./`
3. Deploy.

> Important: put your logo file as `assets/img/logo.png` (PNG recommended).

You can update `sitemap.xml`, `robots.txt`, and Open Graph meta URLs after you know your final production domain.
