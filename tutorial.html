Cara Join Server How to Join the Server

Ikuti langkah berikut untuk masuk ke Cihuy - LegendsPVP #1. Follow these steps to join Cihuy - #1 LegendsPVP Server.

Step-by-step

  1. Buka launcher kalian (bisa Pojav / TLauncher).
  2. Open your launcher (Pojav / TLauncher / any Java launcher).
  3. Masuk ke menu Multiplayer.
  4. Go to the Multiplayer menu.
  5. Klik Add Server / Add Address.
  6. Click Add Server / Add Address.
  7. Masukkan IP: cihuy.xyz (tanpa port).
  8. Enter the IP: cihuy.xyz (no port).
  9. Aktifkan opsi Resource Pack: Enabled.
  10. Enable Resource Pack: Enabled.
  11. Saat pertama join, kamu akan diverifikasi oleh anti-bot. Jika ter-kick, join lagi.
  12. On first join you will be verified by the anti-bot system. If kicked, just rejoin.
  13. Setelah masuk, lakukan registrasi: /register password ulangipassword.
  14. Once inside, register with: /register password passwordagain.
  15. Akunmu siap! Selamat bermain di Cihuy!
  16. Your account is ready! Enjoy playing on Cihuy!
